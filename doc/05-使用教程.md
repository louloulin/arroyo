# 5. 使用教程

## 5.1 快速入门

本节将指导您完成 Arroyo 的基本使用流程，从安装到运行第一个流处理作业。

### 5.1.1 安装 Arroyo

首先，安装 Arroyo：

```bash
# MacOS
brew install arroyosystems/tap/arroyo

# 或使用安装脚本（MacOS/Linux）
curl -LsSf https://arroyo.dev/install.sh | sh
```

### 5.1.2 启动 Arroyo 集群

安装完成后，启动 Arroyo 集群：

```bash
arroyo cluster
```

这将启动一个包含所有必要组件的本地 Arroyo 集群。

### 5.1.3 访问 Web UI

启动集群后，打开浏览器访问 Web UI：

```
http://localhost:5115
```

### 5.1.4 创建第一个流处理作业

在 Web UI 中，点击"创建管道"按钮，然后输入以下 SQL 查询：

```sql
SELECT * FROM impulse()
```

这个查询使用 `impulse()` 源生成测试数据。点击"创建"按钮启动作业。

### 5.1.5 查看作业结果

作业启动后，您可以在 Web UI 中查看作业的状态、指标和输出数据。

## 5.2 使用 SQL 创建流处理作业

Arroyo 支持使用 SQL 创建流处理作业，这是最常用的方式。

### 5.2.1 基本 SQL 语法

Arroyo SQL 遵循标准 SQL 语法，但添加了流处理特定的扩展：

```sql
SELECT [列1], [列2], ...
FROM [源表]
WHERE [条件]
GROUP BY [分组列]
HAVING [分组条件]
```

### 5.2.2 数据源和目标

在 SQL 查询中，您可以使用各种数据源和目标：

```sql
-- 从 Kafka 读取数据
SELECT * FROM kafka_source

-- 将结果写入 Kafka
INSERT INTO kafka_sink SELECT * FROM source_table

-- 从文件读取数据
SELECT * FROM file_source

-- 将结果写入文件
INSERT INTO file_sink SELECT * FROM source_table
```

### 5.2.3 窗口操作

Arroyo 支持多种窗口操作：

```sql
-- 滚动窗口（每5分钟一个窗口）
SELECT 
  window_start, 
  window_end, 
  COUNT(*) as count
FROM TABLE(
  TUMBLE(TABLE source_table, DESCRIPTOR(event_time), INTERVAL '5' MINUTE)
)
GROUP BY window_start, window_end

-- 滑动窗口（每1分钟滑动一次，窗口大小为5分钟）
SELECT 
  window_start, 
  window_end, 
  COUNT(*) as count
FROM TABLE(
  HOP(TABLE source_table, DESCRIPTOR(event_time), INTERVAL '1' MINUTE, INTERVAL '5' MINUTE)
)
GROUP BY window_start, window_end

-- 会话窗口（会话间隔为10分钟）
SELECT 
  window_start, 
  window_end, 
  COUNT(*) as count
FROM TABLE(
  SESSION(TABLE source_table, DESCRIPTOR(event_time), INTERVAL '10' MINUTE)
)
GROUP BY window_start, window_end
```

### 5.2.4 连接操作

Arroyo 支持多种连接操作：

```sql
-- 流-流连接
SELECT a.id, a.name, b.value
FROM stream_a AS a
JOIN stream_b AS b
ON a.id = b.id
WHERE a.event_time BETWEEN b.event_time - INTERVAL '5' MINUTE AND b.event_time + INTERVAL '5' MINUTE

-- 流-表连接
SELECT a.id, a.value, b.name
FROM stream_a AS a
JOIN table_b AS b
ON a.id = b.id
```

### 5.2.5 聚合操作

Arroyo 支持各种聚合操作：

```sql
-- 简单聚合
SELECT 
  user_id, 
  COUNT(*) as event_count,
  SUM(amount) as total_amount,
  AVG(amount) as avg_amount,
  MIN(amount) as min_amount,
  MAX(amount) as max_amount
FROM events
GROUP BY user_id

-- 窗口聚合
SELECT 
  user_id, 
  window_start,
  window_end,
  COUNT(*) as event_count
FROM TABLE(
  TUMBLE(TABLE events, DESCRIPTOR(event_time), INTERVAL '1' HOUR)
)
GROUP BY user_id, window_start, window_end
```

## 5.3 使用连接器

Arroyo 提供丰富的连接器，用于与外部系统集成。

### 5.3.1 创建连接配置

在使用连接器之前，需要创建连接配置：

1. 在 Web UI 中，导航到"连接"页面
2. 点击"创建连接配置"按钮
3. 选择连接器类型（如 Kafka、Kinesis 等）
4. 填写连接参数（如服务器地址、认证信息等）
5. 点击"创建"按钮保存连接配置

### 5.3.2 创建连接表

创建连接配置后，需要创建连接表：

1. 在"连接"页面，点击"创建连接表"按钮
2. 选择连接配置
3. 填写表参数（如主题名称、格式等）
4. 定义表的模式（字段名称和类型）
5. 点击"创建"按钮保存连接表

### 5.3.3 在 SQL 中使用连接表

创建连接表后，可以在 SQL 查询中使用它：

```sql
-- 从 Kafka 连接表读取数据
SELECT * FROM kafka_table

-- 将结果写入 Kafka 连接表
INSERT INTO kafka_sink_table
SELECT * FROM source_table
```

## 5.4 使用用户定义函数 (UDF)

Arroyo 支持用户定义函数 (UDF)，允许您扩展系统的功能。

### 5.4.1 创建 Rust UDF

创建 Rust UDF：

1. 在 Web UI 中，导航到"UDF"页面
2. 点击"创建 UDF"按钮
3. 选择 Rust 作为语言
4. 编写 UDF 代码，例如：

```rust
#[arroyo_udf]
fn multiply(a: i32, b: i32) -> i32 {
    a * b
}
```

5. 点击"创建"按钮保存 UDF

### 5.4.2 创建 Python UDF

创建 Python UDF：

1. 在"UDF"页面，点击"创建 UDF"按钮
2. 选择 Python 作为语言
3. 编写 UDF 代码，例如：

```python
def multiply(a: int, b: int) -> int:
    return a * b
```

4. 点击"创建"按钮保存 UDF

### 5.4.3 在 SQL 中使用 UDF

创建 UDF 后，可以在 SQL 查询中使用它：

```sql
SELECT id, multiply(value1, value2) as product
FROM source_table
```

## 5.5 监控和管理作业

Arroyo 提供多种工具和功能，用于监控和管理流处理作业。

### 5.5.1 查看作业状态

在 Web UI 中，您可以查看所有作业的状态：

1. 导航到"管道"页面查看所有管道
2. 点击特定管道查看其详细信息
3. 在管道详情页面，可以查看作业状态、指标和日志

### 5.5.2 查看作业指标

Arroyo 收集各种作业指标：

1. 在管道详情页面，点击"指标"选项卡
2. 查看各种指标，如吞吐量、延迟、处理时间等
3. 使用时间范围选择器调整指标的时间范围

### 5.5.3 管理作业

您可以执行各种管理操作：

1. **启动作业**：在管道详情页面，点击"启动"按钮
2. **停止作业**：点击"停止"按钮
3. **重启作业**：点击"重启"按钮
4. **修改作业**：点击"编辑"按钮修改 SQL 查询
5. **删除作业**：点击"删除"按钮
