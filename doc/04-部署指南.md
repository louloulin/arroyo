# 4. 部署指南

## 4.1 安装方式

Arroyo 提供多种安装方式，适应不同的部署环境和需求。

### 4.1.1 本地安装

#### 使用 Homebrew（MacOS）

在 MacOS 上，可以使用 Homebrew 安装 Arroyo：

```bash
brew install arroyosystems/tap/arroyo
```

#### 使用安装脚本（MacOS/Linux）

在 MacOS 或 Linux 上，可以使用安装脚本安装 Arroyo：

```bash
curl -LsSf https://arroyo.dev/install.sh | sh
```

#### 从二进制文件安装

也可以从 [GitHub Releases](https://github.com/ArroyoSystems/arroyo/releases) 页面下载适合您平台的二进制文件。

### 4.1.2 Docker 安装

Arroyo 提供官方 Docker 镜像，可以使用以下命令启动：

```bash
docker run -p 5115:5115 ghcr.io/arroyosystems/arroyo:latest
```

### 4.1.3 Kubernetes 安装

Arroyo 提供官方 Helm Chart，用于在 Kubernetes 集群上部署：

```bash
helm repo add arroyo https://arroyosystems.github.io/helm-charts
helm repo update
helm install arroyo arroyo/arroyo
```

## 4.2 部署模式

Arroyo 支持多种部署模式，适应不同的规模和需求。

### 4.2.1 单节点模式

单节点模式适用于开发、测试和小规模生产环境。在这种模式下，所有组件都运行在同一个节点上。

启动单节点集群：

```bash
arroyo cluster
```

### 4.2.2 分布式模式

分布式模式适用于大规模生产环境，提供更高的可扩展性和可用性。在这种模式下，各组件可以分布在多个节点上。

#### 手动启动各组件

1. 启动 API 服务器：

```bash
arroyo api
```

2. 启动控制器：

```bash
arroyo controller
```

3. 启动编译器服务：

```bash
arroyo compiler
```

4. 启动工作节点：

```bash
arroyo worker
```

5. 启动节点服务器：

```bash
arroyo node
```

#### 使用 Kubernetes 部署

在 Kubernetes 环境中，可以使用 Helm Chart 部署 Arroyo 的各个组件。详细配置请参考 [Kubernetes 部署文档](https://doc.arroyo.dev/deployment/kubernetes)。

### 4.2.3 边缘计算模式

Arroyo 计划支持边缘计算模式，允许在资源受限的边缘设备上运行流处理作业。这种模式目前正在开发中。

## 4.3 配置选项

Arroyo 提供多种配置选项，可以通过配置文件、环境变量或命令行参数设置。

### 4.3.1 配置文件

Arroyo 支持 TOML 或 YAML 格式的配置文件。默认配置文件路径为 `~/.arroyo/config.toml`。

示例配置文件：

```toml
[api]
http_port = 5115
bind_address = "0.0.0.0"

[controller]
scheduler = "node"
rpc_port = 8081

[worker]
task_slots = 4
bind_address = "0.0.0.0"
rpc_port = 8082

[compiler]
rpc_port = 8083

[node]
id = 1
```

### 4.3.2 环境变量

所有配置选项也可以通过环境变量设置，格式为 `ARROYO__SECTION__OPTION`。例如：

```bash
export ARROYO__API__HTTP_PORT=5115
export ARROYO__CONTROLLER__SCHEDULER=node
```

### 4.3.3 命令行参数

某些配置选项可以通过命令行参数设置：

```bash
arroyo --config /path/to/config.toml cluster
```

## 4.4 数据库配置

Arroyo 使用数据库存储元数据和状态信息。支持 PostgreSQL 和 SQLite 两种数据库。

### 4.4.1 PostgreSQL 配置

使用 PostgreSQL 作为数据库（推荐用于生产环境）：

```toml
[database]
type = "postgres"
host = "localhost"
port = 5432
user = "arroyo"
password = "arroyo"
database = "arroyo"
```

### 4.4.2 SQLite 配置

使用 SQLite 作为数据库（适用于开发和测试环境）：

```toml
[database]
type = "sqlite"
path = "/path/to/arroyo.db"
```

## 4.5 安全配置

### 4.5.1 认证配置

Arroyo 支持多种认证方式：

```toml
[auth]
type = "basic"  # 或 "oauth", "jwt"
```

### 4.5.2 TLS 配置

配置 TLS 加密：

```toml
[api.tls]
enabled = true
cert_file = "/path/to/cert.pem"
key_file = "/path/to/key.pem"
```

### 4.5.3 授权配置

配置访问控制：

```toml
[auth.rbac]
enabled = true
```

## 4.6 资源配置

### 4.6.1 内存配置

配置内存使用限制：

```toml
[worker]
memory_limit = "4G"
```

### 4.6.2 CPU 配置

配置 CPU 使用限制：

```toml
[worker]
cpu_limit = 4
```

### 4.6.3 并行度配置

配置默认并行度：

```toml
[pipeline]
default_parallelism = 4
```
