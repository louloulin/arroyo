# 3. 核心功能

## 3.1 流处理模型

Arroyo 基于 Dataflow 模型实现流处理，这是一种强大的流处理范式，能够处理无界数据流并提供精确的结果。

### 3.1.1 事件时间处理

Arroyo 支持事件时间处理，这意味着系统可以根据数据中的时间戳（而不是数据到达的时间）处理数据。这对于处理延迟或乱序数据至关重要。主要特性包括：

- **水印（Watermark）**：用于跟踪事件时间的进度，处理延迟数据
- **延迟数据处理**：可配置的策略处理晚到的数据
- **时间属性**：支持在查询中使用时间属性

### 3.1.2 窗口操作

Arroyo 支持多种窗口操作，用于在无界数据流上执行有界计算：

- **滚动窗口（Tumbling Window）**：固定大小、不重叠的窗口
- **滑动窗口（Sliding Window）**：固定大小、可重叠的窗口
- **会话窗口（Session Window）**：由活动会话定义的窗口
- **即时窗口（Instant Window）**：针对单个事件的窗口

窗口操作可以与各种聚合函数结合使用，如 COUNT、SUM、AVG、MIN、MAX 等。

### 3.1.3 状态管理

Arroyo 提供强大的状态管理功能，支持有状态的流处理操作：

- **键控状态（Keyed State）**：基于键的状态管理，支持分区和并行处理
- **全局状态（Global State）**：跨所有分区共享的状态
- **过期状态（Expiring State）**：基于时间的状态过期机制
- **检查点（Checkpoint）**：定期保存状态快照，用于故障恢复

### 3.1.4 连接操作

Arroyo 支持多种连接操作，用于关联不同数据流：

- **流-流连接（Stream-Stream Join）**：连接两个数据流
- **流-表连接（Stream-Table Join）**：将数据流与表连接
- **时间窗口连接（Windowed Join）**：在时间窗口内连接数据
- **查找连接（Lookup Join）**：使用外部系统进行连接

## 3.2 SQL 支持

Arroyo 提供全面的 SQL 支持，使用户能够使用熟悉的 SQL 语法编写流处理查询。

### 3.2.1 SQL 方言

Arroyo 实现了一种扩展的 SQL 方言，专为流处理设计。主要特性包括：

- 标准 SQL 语法（SELECT、FROM、WHERE、GROUP BY 等）
- 流处理特定的扩展（WINDOW、WATERMARK 等）
- 时间函数和操作符
- 用户定义函数（UDF）支持

### 3.2.2 查询优化

Arroyo 使用先进的查询优化技术，提高 SQL 查询的性能：

- 逻辑计划优化
- 物理计划生成和优化
- 分区和并行化策略
- 操作符融合和链接

### 3.2.3 动态查询

Arroyo 支持动态查询，允许在运行时修改查询：

- 查询参数化
- 动态过滤条件
- 查询更新和重启

## 3.3 连接器生态系统

Arroyo 提供丰富的连接器生态系统，支持与各种外部系统集成。

### 3.3.1 源连接器

源连接器用于从外部系统读取数据：

- **Kafka**：从 Kafka 主题读取数据
- **Kinesis**：从 Amazon Kinesis 流读取数据
- **文件系统**：从本地或分布式文件系统读取数据
- **数据库**：从关系型或 NoSQL 数据库读取数据
- **MQTT**：从 MQTT 代理读取数据
- **NATS**：从 NATS 服务器读取数据
- **Redis**：从 Redis 读取数据
- **HTTP**：通过 HTTP 轮询或 SSE 读取数据
- **WebSocket**：从 WebSocket 连接读取数据
- **Fluvio**：从 Fluvio 主题读取数据
- **Impulse**：生成测试数据

### 3.3.2 目标连接器

目标连接器用于将处理结果写入外部系统：

- **Kafka**：写入 Kafka 主题
- **Kinesis**：写入 Amazon Kinesis 流
- **文件系统**：写入本地或分布式文件系统
- **数据库**：写入关系型或 NoSQL 数据库
- **MQTT**：写入 MQTT 代理
- **NATS**：写入 NATS 服务器
- **Redis**：写入 Redis
- **HTTP**：通过 HTTP 发送数据
- **WebSocket**：通过 WebSocket 发送数据
- **Fluvio**：写入 Fluvio 主题
- **标准输出**：写入标准输出（用于调试）

### 3.3.3 格式支持

Arroyo 支持多种数据格式：

- **JSON**：JSON 格式的数据
- **Avro**：Apache Avro 格式的数据
- **Protobuf**：Protocol Buffers 格式的数据
- **Parquet**：Apache Parquet 格式的数据
- **CSV**：逗号分隔值格式的数据
- **纯文本**：纯文本格式的数据

## 3.4 用户定义函数 (UDF)

Arroyo 支持用户定义函数 (UDF)，允许用户扩展系统的功能。

### 3.4.1 Rust UDF

用户可以使用 Rust 编写 UDF，获得最佳性能：

- 支持同步和异步函数
- 支持聚合函数
- 支持标量和表值函数
- 与 Arrow 数据格式无缝集成

### 3.4.2 Python UDF

Arroyo 还支持 Python UDF，提供更高的灵活性：

- 使用熟悉的 Python 语法
- 支持 Python 生态系统的库
- 与 Arrow 数据格式集成

## 3.5 监控和指标

Arroyo 提供全面的监控和指标收集功能：

- **作业指标**：吞吐量、延迟、处理时间等
- **系统指标**：CPU、内存、网络使用情况等
- **自定义指标**：用户定义的指标
- **指标可视化**：通过 Web UI 可视化指标
- **指标导出**：支持导出指标到外部系统（如 Prometheus）
