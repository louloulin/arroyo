# 9. 开发指南

本章节提供了 Arroyo 的开发指南，包括环境设置、代码结构、开发流程和最佳实践。

## 9.1 开发环境设置

### 9.1.1 前提条件

在开始开发 Arroyo 之前，您需要安装以下软件：

- **Rust**：Arroyo 使用 Rust 编写，需要安装 Rust 工具链
- **PostgreSQL**：用于存储元数据和状态信息
- **Docker**：用于运行依赖服务和测试
- **Node.js**：用于构建 Web UI
- **Protobuf 编译器**：用于生成 gRPC 代码

### 9.1.2 安装 Rust

使用 rustup 安装 Rust：

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

安装完成后，确保 Rust 工具链正常工作：

```bash
rustc --version
cargo --version
```

### 9.1.3 安装 PostgreSQL

您可以使用 Docker 运行 PostgreSQL：

```bash
docker run --name arroyo-postgres -e POSTGRES_USER=arroyo -e POSTGRES_PASSWORD=arroyo -e POSTGRES_DB=arroyo -p 5432:5432 -d postgres:14
```

或者在本地安装 PostgreSQL：

```bash
# Ubuntu/Debian
sudo apt-get install postgresql

# MacOS
brew install postgresql
```

### 9.1.4 安装 Node.js

安装 Node.js 和 npm：

```bash
# Ubuntu/Debian
sudo apt-get install nodejs npm

# MacOS
brew install node
```

### 9.1.5 安装 Protobuf 编译器

安装 Protobuf 编译器：

```bash
# Ubuntu/Debian
sudo apt-get install protobuf-compiler

# MacOS
brew install protobuf
```

### 9.1.6 克隆代码库

克隆 Arroyo 代码库：

```bash
git clone https://github.com/ArroyoSystems/arroyo.git
cd arroyo
```

### 9.1.7 构建项目

构建 Arroyo 项目：

```bash
# 构建后端
cargo build

# 构建 Web UI
cd webui
npm install
npm run build
cd ..
```

## 9.2 代码结构

Arroyo 项目采用 Rust 工作空间结构，包含多个 crate。

### 9.2.1 主要 crate

- **arroyo**：主要的二进制 crate，包含命令行接口和入口点
- **arroyo-api**：API 服务器实现
- **arroyo-controller**：控制器实现
- **arroyo-compiler-service**：编译器服务实现
- **arroyo-worker**：工作节点实现
- **arroyo-node**：节点服务器实现
- **arroyo-rpc**：RPC 接口定义
- **arroyo-types**：共享类型定义
- **arroyo-datastream**：数据流处理核心
- **arroyo-state**：状态管理
- **arroyo-storage**：存储接口
- **arroyo-connectors**：连接器实现
- **arroyo-formats**：数据格式处理
- **arroyo-planner**：查询计划生成和优化
- **arroyo-operator**：操作符实现
- **arroyo-metrics**：指标收集和报告
- **arroyo-udf**：用户定义函数支持

### 9.2.2 目录结构

```
arroyo/
├── crates/                  # Rust crates
│   ├── arroyo/              # 主二进制 crate
│   ├── arroyo-api/          # API 服务器
│   ├── arroyo-controller/   # 控制器
│   ├── ...                  # 其他 crates
├── webui/                   # Web UI 代码
├── k8s/                     # Kubernetes 部署配置
├── docker/                  # Docker 相关文件
├── docs/                    # 文档
├── Cargo.toml               # 工作空间配置
└── README.md                # 项目说明
```

## 9.3 开发流程

### 9.3.1 分支管理

Arroyo 使用 Git 进行版本控制，采用以下分支策略：

- **main**：主分支，包含最新的稳定代码
- **develop**：开发分支，包含最新的开发代码
- **feature/xxx**：功能分支，用于开发新功能
- **bugfix/xxx**：修复分支，用于修复 bug
- **release/xxx**：发布分支，用于准备发布

### 9.3.2 开发新功能

开发新功能的流程：

1. 从 develop 分支创建新的功能分支：
   ```bash
   git checkout develop
   git pull
   git checkout -b feature/my-feature
   ```

2. 在功能分支上进行开发和测试

3. 提交代码并推送到远程仓库：
   ```bash
   git add .
   git commit -m "Add my feature"
   git push origin feature/my-feature
   ```

4. 创建 Pull Request 到 develop 分支

5. 代码审查通过后，合并到 develop 分支

### 9.3.3 修复 Bug

修复 bug 的流程：

1. 从 main 或 develop 分支创建新的修复分支：
   ```bash
   git checkout main  # 或 develop
   git pull
   git checkout -b bugfix/my-fix
   ```

2. 在修复分支上进行修复和测试

3. 提交代码并推送到远程仓库：
   ```bash
   git add .
   git commit -m "Fix bug"
   git push origin bugfix/my-fix
   ```

4. 创建 Pull Request 到 main 或 develop 分支

5. 代码审查通过后，合并到相应分支

### 9.3.4 测试

Arroyo 使用多种测试方法确保代码质量：

- **单元测试**：测试单个组件的功能
- **集成测试**：测试组件之间的交互
- **系统测试**：测试整个系统的功能
- **性能测试**：测试系统的性能和可扩展性

运行测试：

```bash
# 运行所有测试
cargo test

# 运行特定 crate 的测试
cargo test -p arroyo-api

# 运行特定测试
cargo test test_name
```

### 9.3.5 代码风格

Arroyo 遵循 Rust 标准代码风格，使用 rustfmt 和 clippy 确保代码质量：

```bash
# 格式化代码
cargo fmt

# 运行 clippy
cargo clippy
```

## 9.4 扩展 Arroyo

### 9.4.1 添加新连接器

添加新连接器的步骤：

1. 在 `crates/arroyo-connectors/src` 目录下创建新的模块

2. 实现 `Connector` trait：
   ```rust
   pub struct MyConnector {}

   impl Connector for MyConnector {
       type ProfileT = MyConfig;
       type TableT = MyTable;

       fn name(&self) -> &'static str {
           "my_connector"
       }

       fn metadata(&self) -> arroyo_rpc::api_types::connections::Connector {
           // 返回连接器元数据
       }

       // 实现其他必要方法
   }
   ```

3. 在 `crates/arroyo-connectors/src/lib.rs` 中注册连接器：
   ```rust
   pub fn connectors() -> HashMap<&'static str, Box<dyn ErasedConnector>> {
       let connectors: Vec<Box<dyn ErasedConnector>> = vec![
           // 其他连接器
           Box::new(my_connector::MyConnector {}),
       ];
       // ...
   }
   ```

### 9.4.2 添加新操作符

添加新操作符的步骤：

1. 在 `crates/arroyo-operator/src` 目录下创建新的模块

2. 实现 `ArrowOperator` trait：
   ```rust
   pub struct MyOperator {
       // 操作符状态
   }

   #[async_trait::async_trait]
   impl ArrowOperator for MyOperator {
       fn name(&self) -> String {
           "MyOperator".to_string()
       }

       async fn process_batch(
           &mut self,
           batch: RecordBatch,
           ctx: &mut OperatorContext,
           collector: &mut dyn Collector,
       ) {
           // 处理数据批次
       }

       // 实现其他必要方法
   }
   ```

3. 创建操作符构造器：
   ```rust
   pub struct MyOperatorConstructor;

   impl OperatorConstructor for MyOperatorConstructor {
       fn construct(
           &self,
           config: OperatorConfig,
           _registry: &Registry,
       ) -> Result<ConstructedOperator, anyhow::Error> {
           // 构造操作符
       }
   }
   ```

4. 在适当的地方注册操作符构造器

### 9.4.3 添加新函数

添加新 SQL 函数的步骤：

1. 在 `crates/arroyo-planner/src/functions.rs` 中定义函数：
   ```rust
   #[derive(Debug)]
   pub struct MyFunction {
       signature: Signature,
   }

   impl Default for MyFunction {
       fn default() -> Self {
           Self {
               signature: Signature::new(
                   TypeSignature::Exact(vec![DataType::Int32]),
                   Volatility::Immutable,
               ),
           }
       }
   }

   impl ScalarUDFImpl for MyFunction {
       fn as_any(&self) -> &dyn Any {
           self
       }

       fn signature(&self) -> &Signature {
           &self.signature
       }

       fn invoke(&self, args: &[ColumnarValue]) -> Result<ColumnarValue, DataFusionError> {
           // 实现函数逻辑
       }
   }
   ```

2. 在 `crates/arroyo-planner/src/lib.rs` 中注册函数：
   ```rust
   pub fn register_functions(registry: &mut Registry) {
       // 其他函数
       registry.add_udf(make_udf_function::<MyFunction>("my_function"));
   }
   ```

## 9.5 调试技巧

### 9.5.1 日志调试

Arroyo 使用 tracing 库进行日志记录，可以通过环境变量控制日志级别：

```bash
# 设置日志级别
export RUST_LOG=debug

# 运行 Arroyo
cargo run -- cluster
```

### 9.5.2 使用调试器

使用 rust-gdb 或 rust-lldb 调试 Arroyo：

```bash
# 使用 GDB 调试
rust-gdb target/debug/arroyo

# 使用 LLDB 调试
rust-lldb target/debug/arroyo
```

### 9.5.3 性能分析

使用 perf 进行性能分析：

```bash
# 记录性能数据
perf record -g target/release/arroyo cluster

# 分析性能数据
perf report
```

## 9.6 文档

### 9.6.1 代码文档

Arroyo 使用 Rust 文档注释记录代码：

```rust
/// 这是一个函数的文档注释
///
/// # 参数
///
/// * `param1` - 第一个参数
/// * `param2` - 第二个参数
///
/// # 返回值
///
/// 返回计算结果
///
/// # 示例
///
/// ```
/// let result = my_function(1, 2);
/// assert_eq!(result, 3);
/// ```
fn my_function(param1: i32, param2: i32) -> i32 {
    param1 + param2
}
```

生成文档：

```bash
cargo doc --open
```

### 9.6.2 用户文档

用户文档位于 `docs` 目录，使用 Markdown 格式编写。
