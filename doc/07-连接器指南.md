# 7. 连接器指南

Arroyo 提供丰富的连接器生态系统，支持与各种外部系统集成。本章节详细介绍了 Arroyo 支持的各种连接器及其配置方法。

## 7.1 Kafka 连接器

Kafka 连接器允许 Arroyo 从 Kafka 主题读取数据或将数据写入 Kafka 主题。

### 7.1.1 配置参数

**连接配置参数**：

| 参数 | 描述 | 必填 | 默认值 |
|------|------|------|--------|
| bootstrap_servers | Kafka 服务器地址列表 | 是 | - |
| security_protocol | 安全协议 | 否 | PLAINTEXT |
| sasl_mechanism | SASL 机制 | 否 | PLAIN |
| sasl_username | SASL 用户名 | 否 | - |
| sasl_password | SASL 密码 | 否 | - |
| schema_registry_url | Schema Registry URL | 否 | - |
| schema_registry_auth | Schema Registry 认证信息 | 否 | - |

**表配置参数**：

| 参数 | 描述 | 必填 | 默认值 |
|------|------|------|--------|
| topic | Kafka 主题名称 | 是 | - |
| group_id | 消费者组 ID | 否（源） | arroyo-[随机ID] |
| auto_offset_reset | 偏移量重置策略 | 否（源） | earliest |
| commit_mode | 提交模式 | 否（目标） | at_least_once |
| key_field | 键字段名称 | 否（目标） | - |
| timestamp_field | 时间戳字段名称 | 否（目标） | - |

### 7.1.2 使用示例

**创建 Kafka 源**：

```sql
-- 创建 Kafka 连接配置
CREATE CONNECTION kafka_conn
TYPE 'kafka'
WITH (
  'bootstrap_servers' = 'localhost:9092'
);

-- 创建 Kafka 表
CREATE TABLE kafka_source (
  id INT,
  name STRING,
  value DOUBLE,
  event_time TIMESTAMP(3),
  WATERMARK FOR event_time AS event_time - INTERVAL '5' SECOND
)
WITH (
  'connector' = 'kafka',
  'connection' = 'kafka_conn',
  'topic' = 'input-topic',
  'format' = 'json',
  'scan.startup.mode' = 'earliest-offset'
);
```

**创建 Kafka 目标**：

```sql
-- 创建 Kafka 表
CREATE TABLE kafka_sink (
  id INT,
  name STRING,
  value DOUBLE,
  event_time TIMESTAMP(3)
)
WITH (
  'connector' = 'kafka',
  'connection' = 'kafka_conn',
  'topic' = 'output-topic',
  'format' = 'json',
  'key.fields' = 'id',
  'sink.delivery-guarantee' = 'at-least-once'
);

-- 插入数据到 Kafka
INSERT INTO kafka_sink
SELECT id, name, value, event_time
FROM source_table;
```

## 7.2 文件系统连接器

文件系统连接器允许 Arroyo 从文件系统读取数据或将数据写入文件系统。支持本地文件系统和对象存储（如 S3、GCS）。

### 7.2.1 配置参数

**表配置参数**：

| 参数 | 描述 | 必填 | 默认值 |
|------|------|------|--------|
| path | 文件路径或目录 | 是 | - |
| format | 文件格式 | 是 | - |
| compression | 压缩格式 | 否 | none |
| pattern | 文件匹配模式 | 否（源） | * |
| write_mode | 写入模式 | 否（目标） | overwrite |
| max_file_size | 最大文件大小 | 否（目标） | 128MB |
| rolling_policy | 文件滚动策略 | 否（目标） | size |
| rolling_size | 滚动大小 | 否（目标） | 128MB |
| rolling_time | 滚动时间 | 否（目标） | 1h |

### 7.2.2 使用示例

**创建文件源**：

```sql
-- 创建文件表
CREATE TABLE file_source (
  id INT,
  name STRING,
  value DOUBLE,
  event_time TIMESTAMP(3),
  WATERMARK FOR event_time AS event_time - INTERVAL '5' SECOND
)
WITH (
  'connector' = 'filesystem',
  'path' = '/data/input',
  'format' = 'json',
  'pattern' = '*.json'
);
```

**创建文件目标**：

```sql
-- 创建文件表
CREATE TABLE file_sink (
  id INT,
  name STRING,
  value DOUBLE,
  event_time TIMESTAMP(3)
)
WITH (
  'connector' = 'filesystem',
  'path' = '/data/output',
  'format' = 'parquet',
  'write_mode' = 'append',
  'rolling_policy' = 'time',
  'rolling_time' = '1h'
);

-- 插入数据到文件
INSERT INTO file_sink
SELECT id, name, value, event_time
FROM source_table;
```

## 7.3 Kinesis 连接器

Kinesis 连接器允许 Arroyo 从 Amazon Kinesis 流读取数据或将数据写入 Kinesis 流。

### 7.3.1 配置参数

**连接配置参数**：

| 参数 | 描述 | 必填 | 默认值 |
|------|------|------|--------|
| region | AWS 区域 | 是 | - |
| access_key | AWS 访问密钥 | 否 | - |
| secret_key | AWS 秘密密钥 | 否 | - |
| endpoint | Kinesis 端点 | 否 | - |

**表配置参数**：

| 参数 | 描述 | 必填 | 默认值 |
|------|------|------|--------|
| stream | Kinesis 流名称 | 是 | - |
| initial_position | 初始位置 | 否（源） | TRIM_HORIZON |
| shard_assigner | 分片分配策略 | 否（源） | uniform |
| key_field | 键字段名称 | 否（目标） | - |
| flush_mode | 刷新模式 | 否（目标） | auto |
| flush_interval | 刷新间隔 | 否（目标） | 1s |
| flush_size | 刷新大小 | 否（目标） | 100 |

### 7.3.2 使用示例

**创建 Kinesis 源**：

```sql
-- 创建 Kinesis 连接配置
CREATE CONNECTION kinesis_conn
TYPE 'kinesis'
WITH (
  'region' = 'us-west-2',
  'access_key' = 'your-access-key',
  'secret_key' = 'your-secret-key'
);

-- 创建 Kinesis 表
CREATE TABLE kinesis_source (
  id INT,
  name STRING,
  value DOUBLE,
  event_time TIMESTAMP(3),
  WATERMARK FOR event_time AS event_time - INTERVAL '5' SECOND
)
WITH (
  'connector' = 'kinesis',
  'connection' = 'kinesis_conn',
  'stream' = 'input-stream',
  'format' = 'json',
  'initial_position' = 'LATEST'
);
```

**创建 Kinesis 目标**：

```sql
-- 创建 Kinesis 表
CREATE TABLE kinesis_sink (
  id INT,
  name STRING,
  value DOUBLE,
  event_time TIMESTAMP(3)
)
WITH (
  'connector' = 'kinesis',
  'connection' = 'kinesis_conn',
  'stream' = 'output-stream',
  'format' = 'json',
  'key_field' = 'id',
  'flush_mode' = 'auto',
  'flush_size' = '100'
);

-- 插入数据到 Kinesis
INSERT INTO kinesis_sink
SELECT id, name, value, event_time
FROM source_table;
```

## 7.4 Redis 连接器

Redis 连接器允许 Arroyo 从 Redis 读取数据或将数据写入 Redis。

### 7.4.1 配置参数

**连接配置参数**：

| 参数 | 描述 | 必填 | 默认值 |
|------|------|------|--------|
| address | Redis 服务器地址 | 是 | - |
| password | Redis 密码 | 否 | - |
| database | Redis 数据库索引 | 否 | 0 |
| cluster_mode | 是否使用集群模式 | 否 | false |
| addresses | Redis 集群地址列表 | 否（集群模式） | - |

**表配置参数**：

| 参数 | 描述 | 必填 | 默认值 |
|------|------|------|--------|
| target | Redis 目标类型 | 是 | - |
| key_field | 键字段名称 | 是 | - |
| hash_field | Hash 字段名称 | 否（Hash 目标） | - |
| ttl | 过期时间 | 否 | - |

### 7.4.2 使用示例

**创建 Redis 连接配置**：

```sql
-- 创建 Redis 连接配置
CREATE CONNECTION redis_conn
TYPE 'redis'
WITH (
  'address' = 'localhost:6379',
  'password' = 'your-password'
);
```

**创建 Redis 目标**：

```sql
-- 创建 Redis 表
CREATE TABLE redis_sink (
  id STRING,
  value STRING
)
WITH (
  'connector' = 'redis',
  'connection' = 'redis_conn',
  'target' = 'string',
  'key_field' = 'id',
  'ttl' = '3600'
);

-- 插入数据到 Redis
INSERT INTO redis_sink
SELECT id, value
FROM source_table;
```

## 7.5 MQTT 连接器

MQTT 连接器允许 Arroyo 从 MQTT 代理读取数据或将数据写入 MQTT 代理。

### 7.5.1 配置参数

**连接配置参数**：

| 参数 | 描述 | 必填 | 默认值 |
|------|------|------|--------|
| broker | MQTT 代理地址 | 是 | - |
| client_id | 客户端 ID | 否 | arroyo-[随机ID] |
| username | 用户名 | 否 | - |
| password | 密码 | 否 | - |
| tls_enabled | 是否启用 TLS | 否 | false |
| tls_ca_cert | CA 证书路径 | 否 | - |
| tls_client_cert | 客户端证书路径 | 否 | - |
| tls_client_key | 客户端密钥路径 | 否 | - |

**表配置参数**：

| 参数 | 描述 | 必填 | 默认值 |
|------|------|------|--------|
| topic | MQTT 主题 | 是 | - |
| qos | 服务质量级别 | 否 | 0 |
| retain | 是否保留消息 | 否（目标） | false |

### 7.5.2 使用示例

**创建 MQTT 源**：

```sql
-- 创建 MQTT 连接配置
CREATE CONNECTION mqtt_conn
TYPE 'mqtt'
WITH (
  'broker' = 'tcp://localhost:1883',
  'username' = 'your-username',
  'password' = 'your-password'
);

-- 创建 MQTT 表
CREATE TABLE mqtt_source (
  id INT,
  name STRING,
  value DOUBLE,
  event_time TIMESTAMP(3),
  WATERMARK FOR event_time AS event_time - INTERVAL '5' SECOND
)
WITH (
  'connector' = 'mqtt',
  'connection' = 'mqtt_conn',
  'topic' = 'input-topic',
  'format' = 'json',
  'qos' = '1'
);
```

**创建 MQTT 目标**：

```sql
-- 创建 MQTT 表
CREATE TABLE mqtt_sink (
  id INT,
  name STRING,
  value DOUBLE,
  event_time TIMESTAMP(3)
)
WITH (
  'connector' = 'mqtt',
  'connection' = 'mqtt_conn',
  'topic' = 'output-topic',
  'format' = 'json',
  'qos' = '1',
  'retain' = 'true'
);

-- 插入数据到 MQTT
INSERT INTO mqtt_sink
SELECT id, name, value, event_time
FROM source_table;
```
