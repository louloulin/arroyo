# 1. 系统概述

## 1.1 Arroyo 简介

Arroyo 是一个用 Rust 编写的分布式流处理引擎，专为高效处理数据流上的有状态计算而设计。与传统的批处理不同，流处理引擎可以同时处理有界和无界的数据源，并在结果可用时立即输出。

简而言之：Arroyo 允许您对高容量实时数据提出复杂问题，并获得亚秒级的结果。

## 1.2 主要特性

- 🦀 支持 SQL 和 Rust 流水线
- 🚀 可扩展至每秒处理数百万事件
- 🪟 支持窗口和连接等有状态操作
- 🔥 状态检查点机制，实现流水线的容错和恢复
- 🕒 通过 Dataflow 模型实现及时的流处理

## 1.3 应用场景

Arroyo 适用于多种实时数据处理场景，包括但不限于：

- 检测欺诈和安全事件
- 实时产品和业务分析
- 实时数据仓库或数据湖摄取
- 实时机器学习特征生成

## 1.4 为什么选择 Arroyo

市场上已经存在一些流处理引擎，如 Apache Flink、Spark Streaming 和 Kafka Streams。Arroyo 的创建是为了解决这些现有系统的一些局限性，并提供以下优势：

### 1.4.1 性能优势

- **高性能**：Arroyo 使用 Rust 编写，具有接近原生的性能，内存占用低，启动时间快。
- **低延迟**：针对实时处理进行了优化，提供亚秒级的处理延迟。
- **高吞吐量**：可扩展至每秒处理数百万事件。

### 1.4.2 易用性优势

- **简单部署**：单一二进制文件，易于部署和管理。
- **SQL 支持**：提供熟悉的 SQL 接口，降低学习曲线。
- **Web UI**：直观的用户界面，便于监控和管理流处理作业。

### 1.4.3 功能优势

- **丰富的连接器**：支持多种数据源和目标，包括 Kafka、Kinesis、文件系统、数据库等。
- **强大的状态管理**：提供可靠的状态管理和检查点机制。
- **灵活的处理模型**：支持各种流处理操作，如窗口、连接、聚合等。

## 1.6 系统要求

- **操作系统**：Linux、macOS
- **内存**：最小 2GB，推荐 4GB 以上
- **存储**：取决于处理的数据量和状态大小
- **网络**：取决于数据源和目标的吞吐量
